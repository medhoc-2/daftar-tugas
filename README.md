# daftar-tugas

Repo ini berisi dua aplikasi:

- **Daftar Tugas** (file `index.html`, `script.js`, `style.css` di folder utama): aplikasi web sederhana untuk mencatat tugas.
- **[Catatan Stok](catatan-stok/README.md)** (folder `catatan-stok/`): aplikasi desktop Windows (Electron) untuk mencatat
  stok, barang masuk, dan barang keluar, lengkap dengan installer `.exe`.
